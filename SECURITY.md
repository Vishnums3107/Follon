# Security policy

Do not report vulnerabilities through public issue trackers. Until a private reporting channel is configured, contact the repository owner directly and include affected component, reproduction steps, impact, and any suggested mitigation.

Never commit broker credentials, tokens, private keys, market-data credentials, customer data, or production audit records. Rotate any credential that is exposed immediately and treat the event as a security incident.

Security requirements and implementation baseline are maintained in [Security architecture](docs/05-quality-security/02-security-architecture.md).
