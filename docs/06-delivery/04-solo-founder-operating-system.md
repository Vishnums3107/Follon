# Solo-founder operating system

## Sustainable allocation

| Focus | Allocation |
| --- | --- |
| Core product engineering | 50% |
| Automated testing and reliability | 20% |
| Security and operations | 10% |
| Documentation | 10% |
| Customer research and support | 10% |

Testing is not spare capacity to trade for more visible features.

## Weekly cadence

- **Monday:** review incidents/risk, select one outcome, update the design document.
- **Tuesday–Thursday:** implement, test, benchmark, and document together.
- **Friday:** run replay and fault-injection suites, security scans, a release candidate/demo, retrospective, and decision log.

Limit work in progress to one major feature.

## Design partners

Starting in month four, interview two professional traders every month. Observe current workflows, record repetitive manual work and actual errors, then prioritize only demonstrated pain. Charge early enough to distinguish interest from willingness to pay.
